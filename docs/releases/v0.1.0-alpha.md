# v0.1.0-alpha — first experimental release

Capsule-Maker is an experimental starting point for portable, reproducible
AI-assisted research handover at the Open Scientific Intelligence Hackathon,
21–22 October 2026. Python distributions use the equivalent prerelease version
`0.1.0a1`; the Git tag and local-plugin version are `v0.1.0-alpha` and
`0.1.0-alpha` respectively. The capsule schema remains `1.0`.

## Implemented workflow

A backend-neutral JSON schema, abstract adapter interface, and working local-file
adapter support deterministic objective/tag selection with dependency closure.
Capsules preserve scientific context, decisions, corrections, superseded attempts,
verified evidence, provenance, hypotheses, and unresolved questions.

The library and CLI assemble, inspect, review, verify, export, and import readable
capsules containing a manifest, summary, ordinary UTF-8 files, dependencies, Python
procedures, and regression tests. Transfer checks SHA-256 integrity, reference
consistency, portable paths, archive limits, likely credentials, and review state.
Import and inspection never execute bundled code. Regression execution requires an
explicit trust decision.

The optional local stdio MCP server exposes the tested core without approval or
code-execution tools. The Agent Skill and local-plugin preparation helper support
coding harnesses with shell access and stdio MCP. The
[creation tutorial](../quickstart-create.md) and
[retrieval tutorial](../quickstart-retrieve.md) provide plugin installation steps
and prompts for separate conversations and different models.

## Deterministic scientific validation

The NumPy Poisson demonstrator solves `-u'' = π² sin(πx)` on `[0,1]` with zero
Dirichlet boundaries and known solution `sin(πx)`. Session A records a rejected
sign choice, its correction, and computed evidence. The exported capsule is
imported by an independent receiving process after deleting Session A's memory.
Its solver regressions and continuation at a new grid resolution validate
second-order convergence. At 256 intervals, local validation produced maximum
error approximately `1.255e-5` and grid-doubling error ratio approximately `4.00009`.

The automated suite covers schema and goal selection, evidence and corrections,
review, round-trip transfer, corruption, secrets, unsafe archives, dependencies,
CLI behavior, numerical correctness, independent processes, actual MCP transport,
and cached local-plugin wiring. CI checks Python 3.11/3.12/3.13, packaging,
wheel-installed handover, and a strict MkDocs build.

**These are deterministic technical checks. Live LLM-agent retrieval and comparisons
across models or reasoning levels remain participant experiments.** The scientific
source records are reproducible fixtures, not an automatically consolidated chat.

## Limitations

- No automatic conversation capture or consolidation.
- Only the local-file memory adapter is implemented; no AOM, Graphiti, Mem0,
  Paper2Agent, BigDFT, or PSolver integration is included.
- Selection uses explicit tags or word overlap, not semantic reasoning.
- Contradictions must be declared or share a claim key; arbitrary language conflicts
  are not understood automatically.
- Only UTF-8 artifacts and capsule schema 1.0 are supported.
- Secret detection is heuristic; approval records are unsigned.
- Checksums establish integrity, not authorship or scientific truth.
- Dependency ranges establish compatibility, not a completely pinned environment.
- Trusted execution is not sandboxed and retains the caller's OS privileges.
- The local plugin has no public catalog listing; install it from the generated
  local marketplace in a compatible harness.

## Next steps

Conduct participant-led fresh-conversation handovers with different models while
preserving transcripts, tool traces, archive hashes, and numerical outputs. Evolve
the capsule format from real transfer requirements. Develop a BigDFT PSolver
scientific demonstrator as a separate milestone. Verify actual AOM interfaces and
map existing consolidated knowledge into the neutral adapter contract.

The Poisson example is a portability test; the meaningful hackathon scientific
application will be selected separately. This release is suitable for experimentation
and contributions, not a claim of production readiness or improved LLM reasoning.
